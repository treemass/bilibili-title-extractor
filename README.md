# B站标题链接Excel提取增强版

[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Version](https://img.shields.io/badge/version-1.25-red)](https://github.com/treemass/bilibili-title-extractor/releases)

> B站收藏夹/视频页一键复制标题和链接，支持Excel格式，与"稍后再看"按钮风格一致

## ✨ 功能特性

- 📋 **右上角主面板**：实时显示当前页面标题和链接
- 🔗 **收藏夹批量复制**：每个视频左上角自动添加复制按钮
- 🎨 **B站原生风格**：按钮与"稍后再看"完全一致
- 🔄 **跨域状态同步**：space 与 www 域名面板状态同步
- 🧹 **智能标题清洗**：自动去除各种尾缀
- 🧹 **智能链接清洗**：自动去除跟踪参数

## 🚀 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 [安装脚本](bilibili-title-extractor.user.js)
3. 确认安装

## 📖 使用

- 打开B站任意页面，右上角出现面板
- 收藏夹页面鼠标悬浮视频封面，左上角出现复制按钮
- 点击复制，直接粘贴到Excel
