# B站标题链接Excel提取增强版

B站收藏夹/视频页一键复制标题和链接，支持Excel格式，按钮与"稍后再看"风格一致。

## 安装

- 通过 GreasyFork 安装（推荐）：https://greasyfork.org/zh-CN/scripts/592592-b站标题链接excel提取增强版
- 通过 GitHub 安装：点击 bilibili-title-extractor.user.js 文件，点击 Raw，Tampermonkey 会自动弹出安装窗口
- 手动安装：下载 bilibili-title-extractor.user.js 文件，在 Tampermonkey 管理面板中选择"添加新脚本"，粘贴全部代码后保存

## 功能

- 右上角主面板：显示当前页面标题和链接，点击复制Excel格式
- 收藏夹批量复制：每个视频卡片左上角自动添加复制按钮，鼠标悬停封面区域时显示
- 跨域状态同步：space.bilibili.com 与 www.bilibili.com 面板状态自动同步
- 标题清洗：自动去除 "-UP主名-稍后再看-哔哩哔哩视频" 等尾缀
- 链接清洗：自动去除 ?spm_id_from= 等跟踪参数，转换为标准视频链接
- 复制时取消收藏：视频播放页点击复制后自动跳出取消收藏选项

## 使用指南

### 视频播放页

1. 打开任意B站视频页面，右上角出现白色面板
2. 面板显示当前视频的标题和链接
3. 点击"复制Excel格式"按钮，标题和链接以 "标题\t链接\t" 格式复制到剪贴板
4. 如果已收藏该视频，将跳出取消选项
5. 点击"隐藏"按钮面板缩成红色小球，再次点击展开

### 收藏夹批量复制

1. 打开收藏夹页面（https://www.bilibili.com/favlist/...）
2. 鼠标悬停任意视频的封面区域
3. 视频卡片左上角出现半透明复制按钮
4. 点击按钮复制该视频的标题和标准链接
5. 复制的数据可直接粘贴到Excel，自动分列为两列

### 保持面板打开

勾选主面板上的"切换页面保持面板打开"：
- 切换页面时面板保持展开
- 新窗口或新标签页继承该状态
取消勾选则页面跳转后面板自动隐藏。
